# Infinity Chimie 🇨🇴

> Plataforma web oficial y catálogo interactivo de **Infinity Chimie (Infinity Pharmaceuticals)** en Colombia. Suplementos farmacéuticos de grado profesional para atletas y culturistas.

---

## 🚀 Características

- **Diseño Moderno en Modo Blanco**: Interfaz limpia, clínica y deportiva con estética farmacéutica de alta gama.
- **Catálogo Interactivo Completo**: Filtros por categorías (SARMs, Orales, Inyectables, Post Ciclo, Quemadores) y buscador instantáneo en tiempo real.
- **Generador de Pedidos a WhatsApp**: Integración directa para pedidos individuales o cotización de múltiples productos en un solo clic.
- **Optimizado & Ligero**: HTML5 semántico, CSS3 modular con variables personalizadas y JavaScript moderno sin dependencias pesadas.
- **Totalmente Responsivo**: Experiencia fluida en dispositivos móviles, tablets y pantallas de escritorio.

---

## 🛠️ Tecnologías

- **HTML5 & CSS3** (Variables CSS nativas, Grid, Flexbox)
- **JavaScript ES6+** (Módulos nativos, filtrado reactivo)
- **Vite** (Servidor de desarrollo ultra rápido y empaquetador)
- **Node.js** (Servidor HTTP nativo de respaldo)

---

## 📦 Instalación y Ejecución

Clona o descarga el proyecto y en la raíz ejecuta:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo (abre automáticamente en tu navegador)
npm start
# o también:
npm run dev
```

### Opciones de ejecución disponibles:

| Comando | Descripción |
| :--- | :--- |
| `npm start` | Inicia Vite y abre automáticamente la app en tu navegador |
| `npm run dev` | Inicia el entorno local de desarrollo con recarga rápida (HMR) |
| `npm run build` | Compila y optimiza los recursos para producción en `/dist` |
| `npm run preview` | Previsualiza localmente la compilación de producción |
| `npm run serve` | Inicia el servidor nativo Node.js sin dependencias en `http://localhost:3000` |
